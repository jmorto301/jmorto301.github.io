Projects

Rain Prototype

To gain a better understanding of GPU instancing and using OpenGL a small rain simulation prototype was created.

During development, the builds were put through stress tests, by rendering increasing numbers of raindrops and measuring the performance with profiling tools and in built performance tools, which helped identify various bottlenecks and areas for optimisation.

More detail about this is available on the project page on Itch.io, along with the shader source code and compiled project.

Ascension

Build Pipeline & Bugfixing, and Feature Implementation

My work mostly focussed on improving/implementing our build pipeline, bugfixing, and feature implementation.

Systems & Tools
I implemented requested features via scripts, but also ensured required parameters could be tweaked from the Unity editor environment and was well documented. This allowed our designers to tweak the feel of mechanics without having to modify the underlying script.
I also focused on staying familiar with the overall structure of the codebase and tracking down bugs.
Build Pipeline
I spent a lot of time managing the project's Git (and later Git LFS) implementation.
This involved getting up to speed with best practices and communicating these to other team members who had focused on other areas, as well as resolving conflicts and helping with other issues as they occurred.

In hindsight, investing more time in early-stage planning would have prevented significant time spent on resolving issues that occured later on. This project was an invaluable lesson in the importance of a clear technical roadmap. It was a great experience in working on a project with a large group of people.
